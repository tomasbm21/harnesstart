# D3 scouting — computer use (fortress)

Lens: agents will be prompt-injected. The screen, CDP socket and accessibility bus are credential-equivalent. Q6 is not “which browser library” — it is **where the pixels and the debugger live, who may attach, and how Tomas seizes the input path**.

## Landscape

Two control planes, not one:

1. **Browser (CDP).** Playwright, Browser Use, Steel, Hermes `browser_exec` / `browser_cdp`. Persistent logins are a Chrome `--user-data-dir` or Playwright `storageState` JSON (both impersonation blobs). Chrome 136+ **refuses** `--remote-debugging-port` on the default profile; Chrome 148 on this VM still prints that warning. CDP itself has **no auth**. Hands-on: `/json/version` on `127.0.0.1:9333` returned protocol 1.3 and a `ws://` URL; `netstat` showed loopback-only. Steel’s own Docker docs expose **9223** and say not to publish it. Orgo’s embed docs: VNC password is **root-equivalent**, no origin allowlist.

2. **Desktop (framebuffer + input).** Hermes `computer_use` → cua-driver (Linux = AT-SPI + XTest). Needs a real `DISPLAY` (Xvfb in a headless VM). Watch/takeover is a **second channel**: noVNC+websockify, KasmVNC, Selkies, xrdp, or Apache Guacamole. Xpra keeps the GUI process alive across disconnects (actual R3 for windows, not just cookies). Lume’s VNC is a **Mac-host** viewer (`vnc://:password@127.0.0.1:port`), not something that runs inside claw-host.

**Where it should run (fortress):** browser + Xvfb/desktop + VNC **inside the agent VM**. Brain may stay on the host but must talk through a **broker** (SSH `-L` or a CDP proxy that does not give the model a raw websocket). Human gateway (Guacamole / tokened websockify) on the **host**, dialing in. Never bind 9222/5900/3389 on a public interface.

**RAM (evidence, not folklore):** one idle Headless Chrome 148 + example.com on this 15 GiB VM summed to **~601 MiB RSS** across processes (environment wrapper also injected SwiftShader and a 1820×1100 window). Shotpipe’s production note: 150–300 MiB per render, leaks until recycle. Steel self-host: **4 GB min**. Kasm default workspace: **2768 MB + 2 CPUs**. Orgo default computer: **4 GB / 1 CPU**. A headed desktop per agent plus Chrome will not 5-wide on a 48 GB Mac without sharing or sleeping sessions.

**Anti-bot:** headless and Playwright-launched Chromium fail Cloudflare Turnstile routinely; attaching CDP to a human-started headed Chrome sometimes passes (anecdote, not a control). Stealth (Camoufox, Steel `--stealth`) is an arms race. **CAPTCHA auto-solve on Steel is a paid cloud plan**, not the Apache-2.0 image. For Norfront ops, the honest v1 is: persistent headed profile + Tomas takeover when challenged — not a solver.

**Takeover UX:** pause agent input (Hermes approvals / bounded cua-driver manifest), then Tomas uses Guacamole or noVNC. `steal=yes` (Xpra) disconnects the other client — define who wins. Do not attach Hermes to Tomas’s real Chrome (`/browser connect`).

## Three surprises

1. **Chrome already treated CDP as an infostealer channel** (2025-03-17 blog): remote debugging ignored on the default profile. This VM’s `/usr/local/bin/google-chrome` wrapper still prepends `--remote-debugging-port=9222 --user-data-dir=/home/ubuntu/.config/google-chrome`. Helpful wrappers reopen the hole.
2. **Orgo documents the failure mode we must not copy:** embed token = desktop password = root shell + terminal websocket, **no origin allowlist**.
3. **Linux computer-use is AT-SPI, not screenshots.** The a11y bus can read password widgets. Isolation is the VM boundary; a host-side cua-driver is game over.

## Open questions

- One headed Chrome+Xvfb vs full XFCE per agent, and who pays the ~0.6–2.7 GiB?
- CDP broker vs raw `ws://` to the model (Hermes `browser_cdp` is an escape hatch)?
- Takeover: Guacamole on host vs noVNC in guest vs Lume VNC on the Mac only?
- Pause `computer_use` during human input, or accept colliding pointers?
- Persist `user-data-dir` on VM disk encrypted, or `storageState` in the secrets broker (Q7)?
- Nested Xvfb+Chrome inside Firecracker: `/dev/shm`, `--no-sandbox`, GPU none — unmeasured.
- When Turnstile trips: Tomas-only, or any solver (R4/R6)?
