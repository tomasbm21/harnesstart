# D6 scouting — commercial landscape (market lens)

Status: unverified. Domain D6. Date seen: **2026-09-20**. No sign-ups (RULES 15).

## Landscape

Agent computers and agent teams are sold as **four different products**, often using the same Firecracker word:

1. **Persistent cloud PC, one per human, many bots.** Grok Bot (Cursor): one Firecracker VM per user; the roster shares disk, cookies, and CLI creds. Docs say this outright. Price is bundled (Cursor Pro **$20/mo** … Ultra **$200/mo**, Teams **$40–$120**/seat). Computers run in the **US**; no on-prem. Closest UX to Claw; opposite of R2-per-agent and R4.
2. **Persistent cloud PC, one per slot you pay for.** Orgo: Hacker **$29** / Startup **$99** / Scale **$399**; Enterprise quotes on-prem. Public regions in the API are US metros. This is the commercial “computer per agent” offer Hermes people already glue to.
3. **Ephemeral microVM sandboxes.** E2B (Hobby $0 + $100 credits; Pro **$150/mo** + ~$0.05/vCPU-h), Daytona (paygo, **US+EU** regions, BYOC runners), Modal (Team **$250**), Runloop (Pro **$250** + dear CPU), Bedrock AgentCore (**$0.0895**/vCPU-h). Isolation is strong; a logged-in ops desktop is not. E2B Embed is the rare Apache-2.0 self-host path.
4. **Agent teams without a computer you own.** Lindy (**$30–$200**/user), Relevance Pro/Team **$19–$349**, Salesforce Agentforce (**$2**/conversation or **$500**/100k Flex Credits), Copilot Studio (**$200**/25k credits), ChatGPT Work/Codex (Plus **$20**, Pro **$200**, Business **$20–$25**/seat). UiPath now sells the same idea **on-prem** (Automation Suite 2.2510.2) at unpublished dollars.

**Q8, as the market actually ships it:** shared SaaS control plane + per-user VM (Grok Bot); per-session microVM (E2B/AgentCore); per-computer subscription (Orgo); BYOC data plane / vendor control plane (Daytona, E2B BYOC, Browserbase BYOS); true customer-operated stack (UiPath Suite, E2B Embed, Factory/Orgo Enterprise “on-prem” as sales language).

**Gap Claw can own (rubric differentiation 5pts + Q8):** a **self-hosted, one-deployment-per-client** swarm where isolation is a **VM per agent or trust zone** (the thing Grok Bot docs warn you not to expect), on **EU-capable hardware the client already understands** (Hetzner-class VPS or their Linux box), with **human gates** and **DeepSeek-class** brains. Hosted players either share one computer (Grok Bot), time-box sessions (E2B), lock the model (Anthropic/OpenAI), or sell RPA to the Fortune 500 (UiPath/Salesforce). Nobody in the seed set sells that package to Norfront-sized ops first.

## Three surprises

1. **Grok Bot is a Cursor SKU**, US-only hosted Firecracker, SuperGrok link optional and **does not stack** with Cursor usage.
2. **ChatGPT “agent” is already the previous name.** Help (updated ~5 days before this scout): use **Work** + cloud browser. Operator.com is dead. Do not write SPEC against “Operator”.
3. **The cheap EU VPS floor moved.** Hetzner CX23 is **€5.49/mo** list and the Cost-Optimized page marks it **not available**. Orgo at $29 is selling convenience over a box that may be stocked-out.
