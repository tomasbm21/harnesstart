# D4 scouting — coordination (fortress)

Lens: agents will be tricked; loops and stalls are security incidents; the human steers without walking into the blast radius.

## Landscape

Chat as the swarm bus is the known-bad shape. BRIEF fact: Tomas’s 3-agent Hermes Discord setup interrupted itself with @mentions. Anthropic’s Research post independently reports early agents “distracting each other with excessive updates,” spawning ~50 subagents on simple queries, and duplicating searches when the lead’s brief was vague. Token use alone explained 80% of BrowseComp variance; MAS burned ~15× chat tokens.

What works instead is a **durable artefact plus a dispatcher**, not a conversation:

- **Board/blackboard (Q5).** Hermes Kanban: every handoff is a SQLite row; workers are OS processes; humans use CLI/dashboard; models use `kanban_*` tools. Swarm v1 is a one-shot graph (root blackboard → parallel workers → verifier → synthesizer) with `idempotency_key`. Comments land on the card and are read on (re-)spawn — they should not barge into a live turn.
- **Supervisor.** Magentic-One / Agent Framework MagenticBuilder: manager + specialists, `max_stall_count` / `max_reset_count` / `max_round_count`, optional plan sign-off. No worker-to-worker chat. The hub is also the injection and token-burn hotspot.
- **Durable HITL (how Tomas steers).** LangGraph `interrupt` + checkpointer; Temporal Signal/`wait_condition` (zero worker-thread cost while waiting); Airflow 3.3 `HITLOperator` parks in `awaiting_input` without holding a worker slot; Restate awakeables (BSL — R4 problem). Mission-command C2: machines accelerate Observe/Orient/Act; a human stays on Decide for irreversible acts; rubber-stamp HITL is automation bias.
- **A2A** is an interop protocol (tasks, cancel, AgentCard), Apache-2.0. Fine between *systems*. Using `SendMessage` as the intra-swarm pager recreates Discord.

**Failure modes in practice (MAST + ops):**

| Mode | Where seen | Guard that is not a prompt |
|---|---|---|
| Loops / step repetition | MAST FM-1.3; CrewAI delegation ping-pong; DeepSeek-V4-Pro identical tool_call (qwen-code#4695) | Client circuit breaker on `(tool, args)` fingerprint; OTP-style MaxR/MaxT; Magentic stall counter |
| Stalls | Magentic `max_stalls=3`; Hermes heartbeat + 4h stale reclaim | Reclaim to `ready`; do not wait in-chat |
| Token burn | Anthropic 15×; CrewAI community: no shared crew ceiling | LiteLLM/gateway budget; **deny must be non-retryable** |
| Duplicate work | Anthropic vague subtask; Kanban missing idempotency | FIX ClOrdID / MsgSeqNum analogue: idempotency_key + claimed-card lock |
| Correlated errors | Debate/vote on a shared prompt; blackboard poison (Terrarium) | Independent seeds; schema+authz on board writes; a verifier that does not trust the board |

**Q9.** Emit OpenTelemetry `gen_ai.*` (R4-safe). Langfuse traces+cost (core MIT; CISO audit-log is EE). Splunk: no ratified agent-step schema yet. Per-run budgets that halt at ~3× lane median (ops blogs; numbers unverified).

**Weaker models (R8).** Put the strongest model in verifier/synthesizer — a weak aggregator can make a council *worse* than the best solo (dev.to bake-off). Prefer few typed tools (`strict` JSON / DeepSeek strict tool_calls) over open delegation. `allow_delegation` default False in CrewAI is the correct default. Do not assume DeepSeek will honour a 90% iteration-budget *notice*.

Fortress bet: **budgets, breakers, and approval gates live in the dispatcher/gateway.** The board is untrusted shared memory.

## Three surprises

1. **Per-agent `max_iter` is not a crew budget.** CrewAI docs: `max_iter` default 20, `allow_delegation` default False. Operators show hierarchical delegation resetting the counter so ping-pong never trips it. Summarising overflow (`respect_context_window`) can erase the audit trail.
2. **The anti-chat-storm pattern is the widest poison radius.** Terrarium (arxiv 2510.14312; ICLR 2026 listing withdrawn — treat ASR as unverified) uses a blackboard specifically to study poisoning and context overflow. Hermes Swarm’s JSON comments are that surface.
3. **microsoft/autogen’s GitHub LICENSE is CC-BY-4.0**, last push 2026-04-15. Successor split: Agent Framework (MIT) + AG2 (Apache-2.0). Do not copy “AutoGen is MIT” from memory.

## Open questions

- Does a Kanban comment notify a *running* worker mid-turn, or only on respawn? Docs say the thread is read when spawned — need a test; this is the Discord-interrupt question.
- Can DeepSeek-class models stick to `kanban_*` instead of inventing chat pings? unknown.
- Nested-virt RAM for Temporal or Airflow beside agent VMs on the Mac: unknown.
- If the verifier is the same weak model as the workers, MAST FC3 (incorrect verification) is correlated — two models or a deterministic contract?
- A2A inside one host vs Kanban: protocol tax vs chat-storm risk. unknown.
